## The line

```
My fridge updated its firmware and now the ice maker is a subscription. I bought a kitchen appliance and got a landlord.
```

120 characters — one line roasting a smart fridge, inside the
200-character limit. Short on purpose: the judge weighs tight wording,
and a punchline should not need a long setup.

## Why this line should land

- **On-subject:** the joke is aimed at the fridge itself — its firmware
  and its ice maker, two things only a smart fridge has.
- **Punchline turns:** "bought an appliance, got a landlord" flips the
  fridge from kitchen box to rent collector in six words.
- **Fresh angle:** no grocery-ordering, no watching-you — the two cracks
  the judge brief calls the obvious ones.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (creating the directory if
needed). The program is deterministic: no randomness, no network, no
clock. It also checks its own output before writing — the entry must be
1–200 characters, a single line, and roast the fridge itself (firmware
/ ice maker).
